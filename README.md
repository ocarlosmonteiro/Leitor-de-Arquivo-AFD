# **Leitor de Arquivos AFD 1510(PIS) e 671(CPF)**

Aplicação desenvolvida em Java para leitura e consulta de arquivos AFD 1510 e 671, permitindo visualizar e filtrar os eventos registrados de forma simples e prática.

O projeto foi desenvolvido com o objetivo de facilitar a análise dos registros, tornando a consulta aos eventos mais rápida e organizada.

## **Funcionalidades**
- **Seleção de arquivo:** permite selecionar um arquivo AFD diretamente do diretório.
- **Filtro por período:** consulta de eventos por data inicial e data final.
- **Filtro por tipo de evento:** permite selecionar:
    - Marcação
    - Inclusão
    - Alteração
    - Exclusão
    - Todos os eventos
- **Visualização dos registros:** apresenta as informações disponíveis de cada evento:
    - NSR (Número Sequencial de Registro)
    - Tipo de evento
    - Data
    - Hora
    - PIS/CPF
    - Nome, quando aplicável aos eventos de inclusão, alteração e exclusão.

## **Como utilizar**
1. Faça o download do executável disponibilizado neste repositório ou clone o repositório para acessar o código-fonte.
2. Execute a aplicação conforme os arquivos disponibilizados.
3. Selecione o arquivo AFD que deseja consultar.
4. Informe o período desejado e selecione o tipo de evento caso desejar.
5. Clique em "Ler arquivo", visualize os registros correspondentes aos filtros aplicados.
